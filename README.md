# Legal Point Launch

Build a modern, premium, professional, bilingual landing page for a legal services and consultation firm called Legal Point.

The website must support Arabic and English languages with a seamless language switcher and proper RTL/LTR layouts.

Project Overview

Legal Point is a professional legal services and consultation office that provides legal consultations, legal representation, contract review, corporate legal services, commercial legal services, and various legal solutions for individuals and businesses.

The website should communicate:

Trust + Professionalism + Expertise + Confidentiality + Authority + Simplicity

The primary goal is to convert visitors into clients by encouraging them to book a consultation or contact Legal Point.

1. Bilingual & Localization Requirements

The website must be fully bilingual:

Languages

Arabic

English

Default Language

Set Arabic as the default language.

Language Switcher

Add a language switcher in the Header:

العربية | English

When Arabic is selected:

Entire website switches to RTL

Arabic content is displayed

Navigation alignment changes appropriately

Icons and directional elements should adapt to RTL

Forms and text alignment should be RTL

When English is selected:

Entire website switches to LTR

English content is displayed

Navigation alignment changes appropriately

Icons and directional elements should adapt to LTR

The language switch should work smoothly without breaking the page layout.

Store the selected language so that the user's preference is preserved when navigating through the website.

Do NOT simply translate individual sections. The entire interface, navigation, buttons, forms, labels, headings, FAQ, footer, and all visible content must support both languages.
